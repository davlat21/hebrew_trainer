Голосовое изучение слов

Нажмите «Включить микрофон», разрешите доступ и скажите START. После озвучивания слова дождитесь надписи «Слушаю» и произнесите следующую команду.

Для MP3-режима сначала подготовьте аудиофайлы на компьютере. Затем выберите этот режим, включите NEXT на наушнике и нажмите START. Голосовые команды при блокировке экрана не поддерживаются.

Управление наушником выключено.

Сначала нажмите START на странице, затем кнопку Play/Pause на наушнике. Если счётчик не меняется — браузер не передаёт нажатия сайту. Работа с заблокированным экраном не гарантируется.

Как пользоваться

START — первое слово на русском. NEXT — это слово на иврите; следующий NEXT — следующее слово на русском. NEW — сначала в текущем порядке. MIX — новый случайный порядок и первое слово на русском. BASE — исходный порядок и первое слово на русском. END — остановить озвучивание и выключить микрофон.

После END включите микрофон кнопкой для новых голосовых команд. Во время озвучивания доступна кнопка END. Для работы микрофона открывайте сайт по HTTPS или через localhost; может потребоваться интернет. Нужны русский голос и голос иврита на устройстве. Распознавание может передавать звук сервису браузера. Вся база доступна через «Мой словарь».
