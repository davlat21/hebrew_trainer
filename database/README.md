# Общая база русско-ивритского словаря

База пока пустая. В неё будут добавляться только присланные слова.
Каждая запись содержит три словарных поля и служебное поле части речи:

- `hebrew` — написание на иврите с присланными огласовками;
- `transcription` — присланная транскрипция;
- `russian` — русский перевод;
- `partOfSpeech` — часть речи для отбора слов по группам.

`words.json` — основной файл данных. `words.js` — его браузерная копия.
`database.js` — доступ и поиск для будущих функций сайта.

После изменения words.json запусти из папки database:

```powershell
py sync_database.py
```

При обновлении базы переноси на сайт оба файла: words.json и words.js.
Проверка перед генерацией блокирует дополнительные поля, пустые значения и
точные повторы. Она не проверяет правильность языка и не исправляет текст.
Разные значения одного ивритского слова могут быть отдельными записями.

Оба JavaScript-файла уже подключены в index.html. Подключение работает и при
открытии index.html с компьютера: fetch и сервер не требуются.

Использование в будущих функциях:

```javascript
const allWords = HebrewRussianDatabase.getAll();
const total = HebrewRussianDatabase.count;
const byHebrew = HebrewRussianDatabase.findHebrew("слово на иврите");
const matches = HebrewRussianDatabase.search("поисковый текст", 20);
```

Поиск учитывает иврит, транскрипцию и русский перевод; сравнение игнорирует
огласовки, регистр и повторные пробелы. Оригинальное написание сохраняется.
Возвращаются копии записей: изменение результатов не изменяет общую базу.

Папка базы отделена от js/data, где находятся вспомогательные данные парсера.
Личный словарь пользователя сохраняется прежним способом в localStorage.
Введи одно русское слово в поле перевода или в быстрый ввод и нажми
«Добавить в словарь». Один найденный вариант добавляется автоматически;
при нескольких вариантах выбери нужный. Слово ищется целиком, включая
основной перевод до уточнения в скобках. Если совпадения нет, ввод сохраняется.

## Части речи

С текущей версии запись имеет дополнительное служебное поле `partOfSpeech`.
Написание на иврите, транскрипция и перевод остаются прежними. Типы групп
описаны в `parts-of-speech.json`. У каждой записи одна основная учебная группа.
Именные выражения относятся к существительным, глагольные — к глаголам.
Обороты, которым нельзя приписать одну часть речи, вынесены в `expression`.
Это учебная классификация конкретного употребления, а не полное описание
всех возможных грамматических ролей слова. При сомнениях используй `unclassified`.

После изменения words.json скрипт sync_database.py обновляет words.js и все
файлы в `groups/`. Эти файлы — производные копии; вручную редактируй words.json.

```javascript
const groups = HebrewRussianDatabase.getGroups(); // Названия и количество.
const verbs = HebrewRussianDatabase.getByPartOfSpeech('verb');
const nouns = HebrewRussianDatabase.getByPartOfSpeech('noun');
const adjectives = HebrewRussianDatabase.getByPartOfSpeech('Прилагательные');
const pronouns = HebrewRussianDatabase.getByPartOfSpeech('pronoun');
```

Методы готовы для будущих режимов обучения. Интерфейс выбора группы пока
не добавлен; текущий поиск русского слова продолжает работать.
