# Общие слова — отдельная база
Источник: вкладка «Общие слова» приложенного Excel.
Только физические строки Excel 9–1426 и 1650–1905 включительно.
Выбрано строк: 1674. Пустых строк: 9. Записей после удаления: 1659.
Строки 1650–1655 содержат по три записи; порядок внутри строки: F, G, H.
Строка 1812 содержит три поля в одной ячейке, разделённые символом |.
Порядок, повторы, написание и транскрипция источника сохранены.
Каждая запись: hebrew, transcription, russian. Транскрипция кириллическая, как в Excel.
Части речи в этой базе пока не размечены.
import-info.json содержит соответствие номеров записей строкам Excel.
words.json — основная база; words.js — браузерная копия для работы без сервера.
API: window.GeneralHebrewRussianDatabase — count, getAll(), findRussian(), findHebrew(), search().
Подключена к index.html отдельно; существующая база и личные слова не изменены.

По запросу удалены записи № 1419–1436 включительно из первоначального импорта (18 записей). Остальные записи сохранены в прежнем порядке.
