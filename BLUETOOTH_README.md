# Голосовой тренажёр

## Запуск на Windows

Распакуйте ZIP целиком. Откройте папку `Program words` и запустите `Start.cmd`. Сайт откроется в браузере по адресу `http://127.0.0.1:8765/index.html`. Оставьте окно сервера открытым до конца занятия. Для голосовых команд нужен браузер с поддержкой Speech Recognition и разрешением на микрофон. Если основной браузер их не поддерживает, откройте тот же адрес в Chrome.

Включите микрофон, выберите готовые MP3 или голос браузера и нажмите START. После каждого слова дождитесь статуса «Слушаю».

| Команда | Действие |
| --- | --- |
| START | Готовит занятие с начала текущего порядка. |
| NEXT | Иврит, русский перевод, затем иврит следующей записи. |
| NEW | Возвращается к началу текущего порядка и озвучивает первое слово на иврите. |
| MIX | Перемешивает все 1 659 записей и озвучивает первое слово нового порядка на иврите. Порядки учитываются до закрытия или перезагрузки страницы. |
| BASE | Восстанавливает исходный порядок и озвучивает первое слово на иврите. |
| RESET | Повторяет последнюю озвученную строку без изменения позиции. |
| END | Завершает занятие. Если микрофон включён, можно сразу снова сказать START. |

## Проверка на iPhone

1. Разместите содержимое папки `Program words` целиком на статическом HTTPS-хостинге и откройте сайт в Safari. Локальный адрес Windows доступен только на компьютере.
2. Подключите Bluetooth-наушники, выберите MP3 и включите «NEXT кнопкой Play/Pause». Нажмите START и NEXT на странице, чтобы начать воспроизведение.
3. Дождитесь окончания слова и нажмите Play/Pause на наушнике. Проверьте, что меняется счётчик и звучит перевод. Следующее нажатие должно открыть следующую запись на иврите.
4. Повторите после блокировки экрана и небольшой паузы. Если счётчик не вырос, Safari или iOS не передали событие сайту. Отдельно проверьте голосовой NEXT, поскольку распознавание речи и аппаратные медиакнопки используют разные API.

Play/Pause работает через Media Session API. Доставка кнопок после окончания короткого клипа при заблокированном экране зависит от Safari, iOS и гарнитуры. Маршрут ввода и вывода звука выбирает операционная система.
