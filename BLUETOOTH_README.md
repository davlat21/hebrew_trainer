# Проверка кнопки наушника на сайте

1. Заменить файлы сайта файлами из папки Program words, сохранив пути. Публикация здесь не выполнялась.
2. Открыть сайт по HTTPS на iPhone. Включить «NEXT кнопкой Play/Pause».
3. Нажать START на странице. Микрофон для режима кнопки не нужен.
4. После окончания русского слова нажать Play/Pause на гарнитуре: ожидается иврит. Следующее нажатие — следующее русское слово.
5. Смотреть «Получено нажатий». Если остаётся 0, Safari/iOS не направляет команды сайту. Переключение настройки в коде не может принудить iOS передавать события.
6. Проверить с открытым экраном, затем при блокировке. Успех на открытой странице не означает работу при блокировке.
7. Остальные команды доступны на сайте. END снимает обработчики гарнитуры.

Эксперимент использует Media Session API. SpeechSynthesis не заменяет полноценный медиаплеер, поэтому сайт может не получить ни одного аппаратного события. Здесь нет предварительно записанных аудиодорожек и нет бесшумного аудио для удержания фоновой сессии. Фоновая работа на iPhone не гарантируется. Надёжный следующий путь — подписанное нативное приложение с проверкой на устройстве.

Содержание обеих баз и прежние алгоритмы разбора текста не изменены.
